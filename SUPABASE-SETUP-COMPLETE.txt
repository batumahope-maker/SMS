TROUBLESHOOTING:
================

Error: "Connection failed"
→ Check internet connection
→ Verify password is correct: batumahope132@
→ Check Supabase project is active

Error: "Table doesn't exist"
→ You need to create tables in Supabase
→ Import your database schema
→ Or use the SQL migration scripts

Error: "pg_connect not found"
→ Enable PostgreSQL in XAMPP
→ Edit php.ini
→ Uncomment: extension=pdo_pgsql
→ Restart Apache
